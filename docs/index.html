CoCreate Device

A shared capability API and envelope bridge for browser and native WebView providers.

Request envelope

{
  method: "device.contacts.select",
  uuid: "request-id",
  device: { properties: ["name", "email", "tel"], options: { multiple: true } }
}

Runtime API

const response = await CoCreate.device.send({
  method: "device.contacts.select",
  device: { properties: ["name", "email", "tel"], options: { multiple: true } }
});

The runtime and build scripts are a scaffold; native host projects are pending.

Repository design references: docs/architecture.md, docs/review.md, and docs/roadmap.md.

See the repository README and src/README.md for setup and bridge details.
